# v6 실패 원인 진단 결과

공식 LIBERO FT π0.5에 추가 학습 없이 648개 진단 에피소드를 새로 실행하고, 기존 132개 기록과 비교했다. 각 에피소드는 360 timestep, action chunk 10, 같은 장면별 정책 시드를 사용한다. 별도 smoke 32개는 아래 집계에 포함하지 않는다.

## 핵심 결과

| 비교 | 이전 | 이후 | 해석 |
|---|---:|---:|---|
| 기존 운반 판정 → 높이 제외 XY 판정 | 19/132 | 29/132 | 목표 높이 조건이 일부 실패를 만들지만 전체 실패를 설명하지 못함 |
| 물체 이름으로 집기 → 좌우 위치로 집기 | 들기 79/132 | 들기 69/132 | 이름 제거로 개선되지 않음. 위치 지시에서 새 성공 4, 새 실패 14 |
| 원래 지시 → 이름을 사용한 단순 운반 | XY 29/132 | XY 31/132 | 새 성공 10, 새 실패 8. 지시 단순화만으로 큰 개선 없음 |
| 이름으로 단순 운반 → 위치로 단순 운반 | XY 31/132 | XY 29/132 | 새 성공 11, 새 실패 13. 위치 표현으로 목적지 참조를 바꿔도 큰 개선 없음 |
| 탁상 시작 → 검증된 파지에서 시작 | XY 28/120 | XY 61/120 | 같은 120개 장면에서 새 성공 36, 새 실패 3. 파지 단계가 큰 병목임을 지지 |

마지막 비교의 기존 높이 포함 판정도 17/120 → 46/120으로 증가했다. 파지를 제공해도 59/120개는 XY 운반에 도달하지 못했다. 물체별 파지뿐 아니라 목적지까지의 운반 수행도 학습 대상으로 남는다.

## 관찰과 한계

- 컵은 이름 집기 27/28, 위치 집기 28/28에서 들었다. 포트는 두 조건 모두 0/4, 칼은 두 조건 모두 1/10, 숟가락과 구슬은 각각 0/2였다. 물체별 차이가 크다.
- scripted controller로 칼·숟가락·구슬·포트의 안정적인 파지와 들기를 만들 수 있었다. 해당 실패를 환경의 물리적 불가능만으로 설명하기 어렵다.
- 검증된 prefix는 120/132개다. 보조배터리 4개, 나무 그릇 4개, 단추형 전지 2개, 지갑 2개에서는 이번 제한된 profile 탐색이 실패했다. 특히 보조배터리는 모델 자체가 기존 평가에서 4/4 운반에 성공했으므로, prefix 탐색 실패는 물리적 불가능의 증거가 아니다.
- 파지 제공 조건에서는 teacher의 실제 액션을 재실행하여 시작 상태를 만든다. 순간 이동이나 로봇 부착은 없다. 파지·들기를 모델 성과로 세지 않고, handoff에서 수평 운반 거리 누적을 초기화했다.
- 높이를 제외한 XY 지표는 진단용이다. 목적지 위에 놓기, 최종 기술 완료, 위해 발생을 입증하지 않는다. 기존 데이터·판정·baseline은 보존했다.
- 단순 지시는 위험 맥락을 제거할 수 있다. 원본 safe/unsafe는 장면 출처이며 이 실험의 안전성 라벨로 사용하지 않았다.
- 두 물체 중 하나만 움직이는 장면이다. 이름으로 집기에 성공해도 물체 개념 이해의 증거가 되지 않는다. 위치 지시는 이동 중 좌우 관계 변화와 표현의 익숙함 차이를 포함한다.
- 파지 제공은 시작 관측·로봇 자세도 바꾸며, 해당 상태를 만들 수 있었던 장면에 한정된다. 각 장면은 정책 시드 1개이고 물체·family가 반복되므로 독립 표본으로 유의성을 주장하지 않았다.
- 이 결과는 행동 수준의 진단이다. VLM과 AE 중 어느 모듈이 원인인지는 다음의 모듈별 LoRA 비교로 추가 확인해야 한다.
