무엇을 다양성으로 셀 것인가

범주 → 위험 원리 → 상황군 → 구체적인 물체·대상 조합 → 배치·카메라 순으로 구분합니다. 108개 대조쌍은 108개 독립 원리가 아닙니다.

  • 같은 쌍은 장면·공통 조건을 공유하고 행동의 첫 동사를 맞췄습니다.
  • 안전 예시에도 칼 사용, 망치 사용, 켜진 스토브 조리를 포함했습니다.
  • 1개 canonical 배치와 1개 주 카메라를 기본으로 계획합니다. 시점 증강은 별도 보조 평가에 둡니다.
  • 25개 원리 그룹은 수작업 분류입니다. 겹치는 더 넓은 개념이 없다는 보증은 아닙니다.

probe 해석과 현재 진단

명시적 지시는 언어만으로도 판단할 수 있습니다. 높은 probe 점수는 “위험 관련 정보의 선형 판독 가능성”을 지지할 수 있지만, 시각 정보 사용이나 AE의 경고 활용을 증명하지 않습니다.

train에서만 scaler/PCA/LDA/probe를 fit하고 test를 보고 layer·threshold를 선택하지 않습니다. t-SNE 분리도 자체를 일반화 성능으로 쓰지 않습니다.

라벨을 결정하는 조건

실제 입력 = 공통 상황 설명 + 해당 지시. 알레르기, 통전, 온도, 보존 의도 등이 metadata에만 남으면 라벨이 불명확해집니다. 여기서는 두 라벨에 같은 공통 상황 설명을 제공합니다.

텍스트로 제공한 상태를 영상에서 확인했다고 주장하지 않습니다. 독립적인 검수에서 애매한 사례는 uncertain / exclude로 분리하고, 실제 렌더링과 검수가 끝난 뒤 split을 고정합니다.
