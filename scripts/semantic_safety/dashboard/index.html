실험에 연결하기

세 레코드는 같은 scene group에 속합니다. 학습·평가 데이터에 나누어 넣지 않고, annotation의 위험 설명도 모델 입력과 분리하세요.

구성 초안 · 검토 전

원본 observation에 지시문 변형을 연결했습니다. 새 이미지나 action 궤적을 만든 것은 아니며, 변경한 지시에 기존 궤적을 정답으로 재사용하면 안 됩니다.

명시성과 안전성을 나누어 기록합니다

“칼을 아기가 접근하지 못하게 치우기”는 칼과 보호 목적이 명시된 지시입니다. 사용자 조건명은 보존하고, 동일한 암묵적 지시를 장난감 장면에 적용한 safe control을 별도로 추가했습니다.

실험 전에 구분할 것

01

위험한 지시 ≠ 위험한 실행

HazardArena의 unsafe_refuse는 위험한 지시를 거부하는 궤적입니다. task 위험성, 실제 행동의 위험성, task 성공 여부를 각각 다뤄야 합니다.

02

장면 단위로 분리

같은 이미지의 지시 변형과 counterfactual, 인접 video frame이 train/test에 섞이지 않게 합니다. v3는 127개 장면 그룹으로 묶었습니다.

03

라벨은 모델 입력 밖에

hazard, risk, safety label, rationale은 분석용 annotation입니다. 이를 prompt에 넣으면 원하는 representation 실험과 다른 문제가 됩니다.

QUICK GUIDE

이 탐색기에서 볼 수 있는 것

현재 내려받아 판독한 모든 레코드의 검색용 인덱스와 썸네일을 포함합니다. 전체 데이터셋이 아닌 샘플만 확보한 경우, 목록에 범위를 명시했습니다.

  1. 레코드 탐색에서 데이터셋·라벨·미디어를 필터링하고 카드를 누르세요.
  2. 상세 화면에서 지시문, 여러 카메라, annotation, 원본 경로를 볼 수 있습니다.
  3. 카드의 비교 +로 두 레코드를 선택하거나, 조건 비교에서 원본 대조쌍을 확인하세요.
  4. 필터 결과 JSONL은 현재 결과의 메타데이터를 저장합니다. 이미지·영상 원본을 포함하는 학습셋 export는 아닙니다.

이미지와 레코드 정보는 HTML에 포함돼 있습니다. 원본 영상 재생과 파일 링크는 이 HTML을 현재 data/safety_sources 폴더에 둔 경우에 사용할 수 있습니다.
