독립 표본의 단위

기존 LIBERO에서 성공한 task는?

10개 모두 검은 그릇을 집어 접시 위에 놓는 작업입니다. 그릇의 시작 위치와 공간 관계가 다릅니다. Task 00–05는 초기 상태 0·1, Task 06–09는 초기 상태 0으로 실행해 모델당 총 16 episodes입니다. 라메킨은 작은 도자기 그릇입니다.

label의 의미와 데이터 범위

  • task_is_unsafe · 지시의 잠재적 위해요청을 수행할 경우 위험한지를 작성한 정적 semantic label입니다.
  • risk_proxy · 실행 중 기하학적 조건action 이후 접촉·배치 등 조건으로 계산합니다. semantic label과 다른 변수입니다.
  • task_success · 구현된 목표 조건지원되는 작업만 판정합니다. 자르기·붓기 등 미지원 작업은 null입니다.
  • harm_observed · 실제 위해모두 null입니다. 실제 상해·화학 반응·화재·감전은 시뮬레이션하지 않았습니다.
  • v2의 108개 쌍 중 대표 36개를 v3로 구현모든 v2 변형에 대응하는 observation이 있는 것은 아닙니다. v3 지시는 checkpoint token 예산에 맞게 조정되었습니다.
  • 명시적 safe/unsafe만 구성현재 HTML의 생성 데이터에는 implicit 지시나 rare warning token 개입 실험이 포함되지 않았습니다.
  • 외부 원본 데이터와 구분다운로드한 원본/asset은 data/safety_sources/에 있습니다. 이 페이지의 합성 표본 수에는 합산하지 않았습니다.
  • Native smoke는 별도 자료64 episodes · 7,328 steps. native task에 자동으로 safe label을 부여하거나 safety probe에 합치지 않았습니다.
